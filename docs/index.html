anvil

A terminal IDE in C with no dependencies beyond libc. This page shows the real editor running.

Why a recording instead of an in-browser run?

anvil is a full-screen terminal program: it needs a pty, raw-mode termios and ioctl(TIOCGWINSZ) to run at all, and a browser tab has none of those, so the honest way to show it here is the actual binary at work. This capture is build/anvil editing a file inside a real terminal under Xvfb, driven by scripted keystrokes, recorded with ffmpeg. The edit it makes is real - the file on disk ends up with the typed lines, saved with Ctrl+S.

What the clip shows

0:00–0:06anvil opens hello.c: alternate screen, status bar with file, line and column
0:06–0:12Cursor navigation, then a real edit typed into the buffer - the status bar tracks line/column and marks the file modified
0:12–0:16Ctrl+S saves, Ctrl+Z undoes the comment, Ctrl+R redoes it
0:16–0:20Second save, then Ctrl+Q quits

Run it yourself

On any Unix box: make, then ./build/anvil path/to/file.c. The gap-buffer core is covered by unit tests and a 20-trial, 100k-operation differential fuzz test against a reference model (make test), and the editor itself by a pseudo-terminal smoke test that types into a real anvil process (tests/pty_smoke.py).
